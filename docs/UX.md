# User Experience

## Primary Screens

### Dashboard

- Spending today
- Spending this week
- Spending this month
- Recent transactions
- Category breakdown
- Planned versus impulse summary

### Quick Entry

Required:
- Amount
- Merchant or description

Optional/defaulted:
- Category
- Planned or impulse
- Notes

Date defaults to current date and time.

### Transaction History

- Chronological list
- Edit and delete
- Category filtering
- Search

### Weekly Reflection

- Total spending
- Category distribution
- Impulse spending
- Simple, nonjudgmental observations

## Action Button

Action Button
  -> App Shortcut
  -> Quick Entry
  -> Save
  -> Dashboard updated

## UX Principles

- Fast entry
- Minimal navigation
- Large, readable amounts
- Clear confirmation after saving
- No unnecessary prompts
- Accessible controls
- Respect reduced-motion settings

## Design Constraint

Manual entry must remain intentional,
but should not become burdensome.
